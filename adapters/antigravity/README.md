# Antigravity

The [official skills page](https://antigravity.google/docs/skills), consulted 2026-10-28, distinguishes:
- App/IDE global: ~/.gemini/config/skills/
- CLI global: ~/.gemini/antigravity-cli/skills/
- Workspace: .agents/skills/

Verify the installed surface/version before using these destinations. Existing antigravity-multiagent came from the App/IDE global root; this does not prove CLI discovery.

Use the generic installer with the selected explicit root. Native subagent schemas, model IDs, Teamwork and execution grants need separate qualification. Do not launch agents or change account/configuration as part of installing files.

The documented automatic/manual invocation choices do not establish a universal manual-only metadata control. Report any enforcement limitation for explicit-only skills.
