# OpenCode

The [official documentation](https://opencode.ai/docs/skills/) lists native .opencode/skills/ and ~/.config/opencode/skills/ roots and compatible .agents/skills/ and .claude/skills/ roots.

Choose one appropriate root and inspect duplicates. Native skill access permissions are a separate configuration concern; Claude frontmatter does not prove equivalent OpenCode activation enforcement.

Install the unchanged package only when its required tools/workflow fit the host. Record discovery, invocation and actual behavior separately. No OpenCode runtime trial is recorded yet.
