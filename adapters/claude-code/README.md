# Claude Code

The [official documentation](https://code.claude.com/docs/en/skills) describes personal ~/.claude/skills/ and project .claude/skills/ packages.

Preserve disable-model-invocation: true for an explicit-only skill. user-invocable controls menu availability and is not a substitute for blocking model invocation. Do not add forked context, hooks, permissions or tool grants merely to install a skill.

Use an explicit installer destination, inspect duplicate names, then verify discovery, explicit invocation and automatic-invocation behavior in the actual version. No Claude runtime trial is recorded yet.
