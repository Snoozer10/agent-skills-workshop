# 0001 — Source and installed skills

Status: accepted initial setup, 2026-10-28.

The workshop repository owns reviewed source. Global directories contain explicitly deployed copies. Initial imports preserve exact bytes and historical hashes; imported claims are not automatically endorsed.

Use small Python maintenance tools and standard unittest checks. Keep categories in catalog metadata and skill folders shallow. Add host-specific packaging only for demonstrated needs.

Installation uses retained receipts and drift checks rather than symlinks, so development edits do not silently alter every agent. It supports recoverable directory moves, not an uninterrupted atomic swap.

Public distribution and licensing remain pending provenance review. No host launch or global installation belongs to initial repository setup.
